# Asclepius

A personal CLI security lab for models, chatbots, RAG applications, and other LLM
systems you own or have permission to test.

Save application profiles, start background evaluations manually, inspect run history,
and generate local reports and charts. Execution is still planned. The implementation
branch provides CLI help and configuration validation alongside the legacy API prototype.

Start with the [documentation index](docs/README.md).
The [backend design](docs/specs/backend-design.md) describes the planned CLI runtime
and four-agent execution architecture.
